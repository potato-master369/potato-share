# deadsimple

A super minimalist theme for Potato Share. Sample theme.

## Features

* CSS has been ripped out of most pages.
* Uses `<table` for better compatibility.
* *MOST* JS has been ripped out. The script for progress bar has been kept because it is useful.
* icons have been removed from `list.html`

## Use cases
Low-bandwidth, or crappy computers. `grid.html` remains mostly unchanged, because it is meant for mobile interfaces, and those that are old enough to not work with that, are probably too old to SHOW a UI anyways.
